Student Performance Prediction
Project Description:
Student Performance Prediction is a Python-based project that predicts a student's final examination score based on study hours, attendance percentage, and previous examination score.
This project is implemented using core Python without external libraries.

Features:
- Takes student details as input
- Uses study hours for prediction
- Uses attendance percentage
- Uses previous examination score
- Predicts final examination score
- Displays performance category
- Displays Pass/Fail result

Technologies Used:
- Python
- Core Python
- Basic Mathematics
- Linear Regression Concept

Input:
The program asks the user to enter:
1. Study hours per day
2. Attendance percentage
3. Previous examination score

Output:
The program displays:
- Predicted final score
- Performance category
- Pass/Fail result

How to Run:
Make sure Python is installed on your computer.
Run:
python student_performance.py

Performance Categories:
- 90–100: Excellent
- 75–89: Very Good
- 60–74: Good
- 40–59: Average
- Below 40: Needs Improvement

Project Purpose:
The purpose of this project is to demonstrate the use of Python programming, mathematical calculations, and machine-learning concepts for predicting student academic performance.
